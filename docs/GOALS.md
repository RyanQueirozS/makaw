# Goals

## Vision

This project aims to create a graphics library/framework like that of raylib,
designed for games and performance critical applications.

We hope for:
- Easier Low-level Customization
- High-level Simplicity
- Version Stability
- Compatibility

It should be stated that optizations for a specific scenario should be done by
the user of the lib, and `Makaw` will only help the end-user to accomplish that
goal through utilities and pipeline management.
